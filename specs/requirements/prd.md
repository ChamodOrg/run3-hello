# Hello World

## Problem Statement

There is no minimal web app to confirm that the platform can build, deploy and serve a web page end to end.

## Solution

A single-page web app that shows "Hello, World!" to any visitor, with no sign-in.

## Actors

- Visitor: anyone who opens the app; sees the greeting. No account needed.

## Features

- F1 [Greeting](features/F1-greeting.md)

## Product-wide

See [Product-wide](product-wide.md).

## Out of Scope

- Sign-in or user accounts.
- Personalised greetings.
- Any backend, storage or external service.
